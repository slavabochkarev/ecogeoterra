# CR-007 · Единый экземпляр ЭкоГеоТерры

**Дата перехода** — 20 ноября 2026 года. **База перед изменениями** — `3ad1bbc`, чистая рабочая копия ветки `main`.

## Исходное и целевое состояние

Ранее `8001` обслуживал старый OSM, `8002` добавлял настройки подложек кадастрового эксперимента, `8003/map` был актуальным Map First. Ранее наблюдались разные наборы загруженных маршрутов при общей точке входа `app.main:app`. Точные рабочие каталоги и переменные старых процессов на момент перехода проверить невозможно: на 8000–8003 уже не было слушателей. Текущие scopes окружения не задавали `RESEARCHES_DIR` или настройки радиусов. В каталоге переносимой копии обнаружены кеш и логи; другого каталога исследований в этом месте не было.

Целевой экземпляр — один worker Uvicorn на `127.0.0.1:8000`. Источник данных — существующая папка `data/researches`, без переноса в другой рабочий каталог. `start.ps1` задаёт 1000 м при отсутствии явного флага, учитывает конфигурацию окружения, оставляет 2000 м выключенным в штатном профиле и вызывает Uvicorn в том же окне. Используется подготовленная `.venv`; установка выполняется при создании или с `-InstallDependencies`.

| URL | Интерфейс |
|---|---|
| `/` | Map First |
| `/map` | Тот же Map First, HTTP 200 |
| `/legacy/osm` | Старый интерфейс OSM v0.2, включая кадастровое обогащение |
| `/legacy/cadastre-experiment` | Кадастровый эксперимент 500 м |
| `/cadastre-experiment` | Совместимый адрес того же эксперимента |

Геоданные и хранилище обслуживаются прежними `/api/*` маршрутами. Имена API, алгоритмы геометрии, отчёты, схема JSON и дизайн Map First сохранены. Legacy-страницы со старых портов доступны на одном origin через новые пути. Картографические ресурсы продолжают загружаться из тех же `/static` и источников тайлов.

## Переключение и сохранность

1. Сверены Git, сетевые слушатели, отсутствие конкурирующего экземпляра и эффективный каталог рабочего состояния.
2. Создана закрытая локальная копия под `%LOCALAPPDATA%\EcoGeoTerra\backups\CR-007-*`. Она содержит `researches`, конфигурацию, исходные файлы запуска и маршрутизации для отката. Секреты копируются только в этот локальный каталог.
3. Проверены SHA-256 13 файлов данных и открытие всех четырёх исследований после восстановления в отдельную временную папку. В четырёх исследованиях есть кадастр, в одном есть OSM. В копии подтверждён активный указатель.
4. Новый маршрут и интерфейсы проверены на 8000 со временной копией хранилища и ответами-фикстурами. Только после успешного smoke тестовый процесс остановлен через Ctrl+C.
5. На 8000 запущен штатный скрипт с существующим каталогом. Прочитаны список, сохранённые данные и отчёт активного исследования. На 8001–8003 не было процессов для остановки. Контрольные суммы рабочих файлов повторно проверены.

## Проверки

| Проверка | Результат |
|---|---|
| HTTP и маршруты | `/`, `/map`, обе legacy-страницы, старый адрес эксперимента и локальные CSS/JS вернули HTTP 200. |
| Прикладные контракты | 19 операций API и OpenAPI-компоненты совпали с версией до перехода. |
| Браузер на фикстурах | Leaflet, тайлы OSM и Esri, варианты адреса, координаты, кандидаты и выбор участка, точный номер, кадастровый запрос 1000 м и слой OSM. |
| Рабочие исследования и отчёты | Открыта копия существующего исследования. Создано, сохранено и повторно открыто отдельное исследование с кадастром и OSM. Обе вкладки и два файла Markdown проверены. |
| Legacy | OSM построил выборку, кадастровый эксперимент построил результат 500 м. Проверены назначение ссылок и прежнего URL эксперимента. |
| Запуск и радиусы | Один слушатель на 8000. Старт при занятом порте отклонён. Штатные capabilities 500/1000 м, 2000 м выключен. Явные переопределения покрыты локально. |
| Автотесты | 7 тестов из `tests/test_api.py` прошли, включая проверку соответствия страниц их скриптам. |

Живые ответы НСПД, Overpass и Nominatim и качество боевой подложки Esri в рамках CR-007 не проверялись. Панель Esri и тайлы в smoke использовали подменённые ответы. Готовые архивы Windows относятся к прежнему выпуску.

## План отката

- При критическом отказе остановить только принадлежащий пользователю экземпляр 8000 через Ctrl+C. Если уже есть новые пользовательские правки, сначала создать согласованную копию текущих файлов исследований.
- Для возврата прежней маршрутизации восстановить из `settings` проверенные предыдущие версии `app/main.py`, `app/static/index.html`, `app/static/cadastre-experiment.html` и при необходимости `start.ps1`. Сопоставить локальные изменения перед восстановлением. Это возвращает legacy OSM на `/`, Map First на `/map`.
- Из корня проекта запустить прежний профиль в отдельном окне PowerShell при свободном 8003:

```powershell
$env:NSPD_RESEARCH_ENABLE_1000 = '1'
$env:NSPD_RESEARCH_ENABLE_2000 = '0'
.\.venv\Scripts\python.exe -B -m uvicorn app.main:app --host 127.0.0.1 --port 8003 --workers 1
```

- Проверить `/api/health`, `/map` и список исследований на 8003. Совместимое рабочее хранилище остаётся на месте. Резервную копию данных восстанавливать в отдельный каталог только при подтверждённом повреждении и затем переключать `RESEARCHES_DIR`.
- Снова используйте один рабочий экземпляр. Возврат 8001 и 8002 не требуется для доступа к legacy.
