## Что не подтверждено в этом выпуске

**Успешная загрузка живого Overpass, непустой список и сквозное скачивание JSON/CSV именно из собранного EXE не подтверждены:** основной публичный сервер вернул HTTP 502. Экспорт и обработка геоданных сохранены; прежние проверки прототипа не выдаются за проверки EXE.

Повторный запуск EXE с переменной `OVERPASS_URL`, указывающей на альтернативный публичный сервер, был заблокирован автоматической проверкой разрешений инструмента (`blocked by policy`). Этот запуск не выполнялся; настройки системы и защиты не менялись. Это ограничение проверки, а не полученная ошибка альтернативного Overpass.

Нет отдельной чистой машины/VM с Windows 10/11 без установленного Python. На сборочной машине Python есть, поэтому тест с очищенным PATH и наличием всех DLL в `onedir` не заменяет испытание на такой машине. Запуск на Windows 10 отдельно не выполнялся.

Не проверялось закрытие окна во время активного запроса Overpass. Для этого случая в оболочке предусмотрены сигнал мягкой остановки и ограниченное ожидание с завершением только собственного дочернего процесса.

## Проверка состава и ZIP

Сборка включает только необходимые Python-модули, двоичные библиотеки, статические ресурсы и явно перечисленные пользовательские документы. `scripts/package_windows.py` проверяет PE x64, обязательные ресурсы, отсутствие известных каталогов/файлов разработки и CRC каждого файла ZIP.

В дистрибутив не добавляются `.venv`, `.cache`, локальные журналы, `.env`, временные QA-ответы, тесты, исторические отчёты и скриншоты. Публичный `certifi/cacert.pem` включён для HTTPS; это не секретный ключ.

После ZIP-сборки рядом с архивом создаётся `EcoburoGeo-v0.1-win64.zip.sha256`. Сам архив содержит папку `EcoburoGeo/` с EXE, `_internal` и инструкциями. Переносить следует весь архив/папку.

Предупреждения PyInstaller о необязательных модулях (POSIX, WebSocket, uvloop, tzdata и др.) просмотрены. Приложение использует asyncio/h11 без WebSocket и UTC для меток времени. Hook PyProj сообщил об отсутствующем альтернативном каталоге `.venv/Library/share/proj`; фактический каталог `pyproj/proj_dir/share/proj` с `proj.db` найден в сборке.

Снимок интерфейса, фактически обслуженного EXE: `docs/windows-release.jpg` в исходном проекте. Он не входит в ZIP и не показывает успешную выдачу объектов.

OpenStreetMap не является официальным кадастровым источником; классификация по тегам не устанавливает юридический ВРИ. Доступность публичных Nominatim, Overpass и тайлов не гарантируется переносимой упаковкой.
