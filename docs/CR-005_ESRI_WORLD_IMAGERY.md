# CR-005. Esri World Imagery

19 ноября 2026 года. Страница `/cadastre-experiment` предлагает три базовые карты. При открытии страницы выбран OpenStreetMap. EOxCloudless и Esri World Imagery включаются через тот же переключатель Leaflet.

## Подключение

- Esri Leaflet 3.0.19 поставляется как локальный JS-файл с лицензией. При выборе Esri создаётся `L.esri.tiledMapLayer` с токеном и URL `https://ibasemaps-api.arcgis.com/arcgis/rest/services/World_Imagery/MapServer`. SDK запрашивает метаданные сетки, затем браузер запрашивает JPEG для текущего окна напрямую у Esri. В авторизованном режиме доступны снимки до максимума карты z19. Замер на контрольной точке не гарантирует того же разрешения снимков во всех регионах. [Esri Leaflet](https://developers.arcgis.com/esri-leaflet/api-reference/layers/tiled-map-layer/) · [Официальный пример World Imagery](https://developers.arcgis.com/esri-leaflet/maps/raster-tile-basemaps/display-multiple-basemap-layers/)
- Переключатель меняет только базовый слой и связанные с ним сведения об источнике. Контуры ЕГРН, исходный участок, буфер 500 м, категории, подписи и измерение остаются на той же карте. OSM, EOxCloudless и Esri рисуются в одном экземпляре Leaflet. Запросы НСПД по-прежнему запускаются при поиске и исследовании.
- При активном Esri заголовок показывает ссылку на World Imagery. В правом нижнем углу карты отображаются `Powered by Esri` и полный текст `copyrightText` из авторизованных метаданных сервиса. Он включает Esri, Vantor, GeoEye, Earthstar Geographics, CNES/Airbus DS, USDA, USGS, AeroGRID, IGN и GIS User Community. Слева остаётся метрическая шкала. В тесте атрибуция появилась с Esri и исчезла при смене подложки. [Требования Esri Leaflet](https://developers.arcgis.com/esri-leaflet/terms-of-use/) · [Требования к атрибуции Esri](https://developers.arcgis.com/documentation/glossary/esri-attribution/)

## Настройка ключа

1. В корне рабочей копии создайте локальный `.env` из `.env.example`. Задайте `ESRI_API_KEY` действующим значением из ArcGIS Location Platform. Для упакованной программы `.env` можно положить рядом с EXE. Заданная в процессе переменная `ESRI_API_KEY` имеет приоритет перед файлом. Пустая переменная процесса отключает Esri.
2. В учётных данных ArcGIS оставьте минимальные права и ограничения HTTP Referrer. В список разрешённых адресов включите фактический внешний адрес страницы по правилам Esri. Запросы из браузера были проверены на `http://127.0.0.1:8001` и `http://127.0.0.1:8002`. [Учётные данные и ограничения ArcGIS](https://developers.arcgis.com/documentation/security-and-authentication/api-key-authentication/api-key-credentials/location-platform/)
3. Перезагрузите страницу для получения новой конфигурации. При отсутствии ключа доступны OSM и EOxCloudless.

Файлы `.env` и `esri.env` исключены правилами `.gitignore`. Для текущей копии переданное значение перенесено из `esri.env` в `.env`. Приложение возвращает браузерный токен из одноимённого API конфигурации подложек с `Cache-Control: no-store` и `Cross-Origin-Resource-Policy: same-origin`. Браузерный токен **виден пользователю приложения** в DevTools, в том числе в параметрах исходящих запросов SDK. Хранение в `.env` защищает от попадания в исходники, а ограничения ArcGIS задают область использования токена. Проба с `Authorization: Bearer` из браузера не прошла CORS на выбранном хосте, поэтому используется параметр токена официального SDK. Диагностика приложения формирует сообщения из известных кодов и не выводит URL запросов, тексты Esri или значения конфигурации. [Авторизация Esri](https://developers.arcgis.com/esri-leaflet/access-tokens/) · [Заголовки авторизации ArcGIS](https://developers.arcgis.com/documentation/security-and-authentication/reference/http-authorization-headers/)

## Ошибки

- При отказе метаданных или тайм-ауте 12 секунд слой прекращает загрузку для текущего выбора. Для ответов 401/403, 498/499 и 429 есть сообщения об авторизации, сроке действия, правах или лимите. 403 требует проверки прав доступа к сервису и внешнего адреса в списке HTTP Referrers.
- При ошибках отдельных JPEG отображается сообщение о полной или частичной загрузке. Для распознавания кода выполняется не более одной диагностической попытки по одному неудавшемуся тайлу за включение Esri. При полном отказе с известным кодом авторизации или лимита запросы прекращаются до нового выбора слоя. При сетевом отказе или непрозрачном ответе браузера показывается общее сообщение. Кнопка «К OpenStreetMap» возвращает OSM в том же окне карты.
- Используется авторизованный хост Esri. Проксирование, собственный кеш снимков и анонимный резервный Esri не используются. [Условия Esri Leaflet](https://developers.arcgis.com/esri-leaflet/terms-of-use/)

## Будущий запуск в Docker

Передавать `ESRI_API_KEY` контейнеру как переменную процесса через `--env-file` или `env_file` Compose. Не включать локальные файлы с ключом в образ или контекст будущей сборки. Внутренний адрес и порт Uvicorn выбираются отдельно от публикуемого адреса. Например, обратный прокси может предоставлять HTTPS пользователю, а Uvicorn слушать внутренний порт контейнера. В ArcGIS разрешается адрес, который видит браузер, а не внутреннее имя или порт контейнера. Для опубликованного приложения ограничить доступ к нему и проверить новый origin в браузере. Токен, переданный SDK, при любом способе запуска доступен клиенту.
