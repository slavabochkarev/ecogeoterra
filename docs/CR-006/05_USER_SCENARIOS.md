# CR-006 · Пользовательские сценарии

| Сценарий | Основной ход | Варианты и итог | Связь |
|---|---|---|---|
| S-01 · Известный кадастровый номер | Ввести номер → «Найти» → увидеть исходный контур → «Исследовать» при исходных 500 м → выбрать соседа. | Без валидного контура исследование недоступно. Ошибка сохраняет ранее подтверждённый участок. Успех показывает буфер, счётчики, полноту и карточку выбранного. | FR-002–003, FR-005–007, FR-012, FR-015 |
| S-02 · Исследование по адресу | Отправить адрес → выбрать один результат Nominatim → увидеть ориентир → «Найти участок у точки» → прочитать отношения кандидатов → подтвердить один участок с контуром → «Исследовать». | При нескольких попаданиях выбор обязателен. Адрес-кандидат не означает совпадения с кадастровым адресом. При отсутствии подходящего контура можно задать точный номер или уточнить ориентир. | FR-002, FR-004, FR-006 |
| S-03 · Координаты и работа с точкой | Ввести координаты в поиск либо открыть «Координаты» → перейти → скопировать координаты; при необходимости сделать точку ориентиром → явно выполнить подбор. | Клик по фону даёт справочную точку. Режим задания ориентира позволяет поставить и перенести маркер. Недопустимые координаты выделяются; клавиатурой можно исправить поля или скопировать значение вручную. Камера при переходе меняется по команде. | FR-002, FR-004, FR-013 |
| S-04 · Увеличение радиуса | Получить 500 м → выбрать 1000 м → увидеть прежний набор и его фактический радиус → «Исследовать» → дождаться нового набора → повторить для 2000 м после допуска. | Ошибка, 429, явное усечение или отмена оставляют предыдущий результат. Успешный результат с неизвестной полнотой или локальными пропусками видимо маркирован. Задержанный ответ 1000 м не применяется, если пользователь уже сменил параметры. | FR-005–007, FR-019, NFR-003–004 |
| S-05 · Включение OSM | После задания ориентира включить «Объекты карты» → увидеть загрузку или кеш → выбрать объект → открыть «Объекты». Отключить/вернуть слой, убедиться в сохранении набора. | Изменить радиус. Чужой OSM-набор скрыт. «Загрузить объекты» для текущего ключа создаёт не более одного запроса на промах. Кадастр остаётся виден. Сбой Overpass не блокирует его. | FR-009–011, FR-014, NFR-002 |
| S-06 · Работа со списком OSM | Выбрать категорию, скрыть безымянные, открыть следующий блок списка, перейти к объекту и выгрузить отфильтрованные результаты. | CSV и GeoJSON отражают источники, действующий радиус и выборку. Карточка Map First показывает сведения OSM. Кадастровое обогащение доступно на старой странице OSM. | FR-011, FR-019 |
| S-07 · Перекрытие | На участке присутствует видимый OSM-объект. В «Кадастре» клик выбирает участок → «Объекты в точке» → выбрать OSM → открывается «Объекты». Повторный клик при прочих равных имеет приоритет OSM. | «Координаты» сохраняет последний предметный приоритет. Любой видимый объект можно также выбрать из списка. Клик по геометрии сохраняет положение справочного маркера. | FR-013–015 |
| S-08 · Расстояние | Выбрать соседний участок с зазором → увидеть расстояние и линию → выбрать касающийся/пересекающийся и прочитать статус → скрыть и вернуть границы. | Для нулевой дистанции — без линии. Если расчёт невозможен, карточка сообщает об этом. При скрытии границ линия и обводки возвращаются с прежним выбором. | FR-012, FR-015, FR-017 |
| S-09 · Панели и подложка | В открытом «Кадастре» переключить «Спутник» → свернуть панель → войти в «Вся карта» → сменить размер окна → выйти кнопкой или Esc. | Центр, zoom и измерения сохранены. На узком экране открывается нижний лист. При ошибке Esri вернуть OSM одним действием. Системный fullscreen опционален. | FR-008–009, FR-016–018 |
| S-10 · Сбой и восстановление | После успешного исследования получить 429, дождаться окончания cooldown и повторить вручную. В отдельном проходе прервать поиск сменой исходного и открыть настройки слоёв. | Сообщение относится к нужной операции. Старый ответ игнорируется, предыдущий принятый набор виден для текущего подтверждённого участка. Закрытие UI не создаёт сетевой запрос. | FR-007, FR-019, NFR-002–004 |

## Переходы данных

| Событие | Исходный объект и кадастр | OSM и интерфейс |
|---|---|---|
| Старт | Источника нет, черновой радиус 500, карта без исследованных участков | OSM выключен, панель закрыта |
| Новый текст/кандидаты либо справочный клик | Подтверждённый объект и нанесённый результат сохраняются до явной смены | Справочная точка отдельно от ориентира, сетевой запуск только по команде |
| Явно изменить ориентир | Когда прежний подтверждённый участок связан с прежней точкой, он и его выборка уходят с карты, остаются в кеше. Подтверждение нового участка отдельное | OSM старого ключа скрывается, предложить загрузку по текущим параметрам |
| Явно выбрать иной контур | Прежние контуры исследования заменяются выделенным новым исходным, выбор и линия от предыдущего контекста уходят с карты | Пересчитать ключ ориентира. Совпадающие точка/радиус могут использовать актуальный OSM-кеш |
| Изменить радиус | Старый буфер и его подпись, запрос отменяется для данного отображения, старые контуры не смешиваются с новыми | OSM проверяет текущий ключ, сетевых эффектов нет |
| Принять результат | Атомарный коммит только актуального ответа с проверкой версии контура. Сохранённый ID восстанавливается при наличии | Кадастровая загрузка не инициирует OSM |
| Закрыть панель или переключить режим | Данные/линии сохранены | Видимые инструменты и фокус меняются по матрице |

## Рабочие исследования (5.1)

| Сценарий | Ожидаемый результат |
|---|---|
| «Новое» до исходного участка | Активный черновик с названием по координатам или «Новое исследование». При выборе участка появляется адрес и кадастровый номер. |
| «Новое» после выбора | В новый черновик входит исходный участок и параметры работы. Выборки предыдущего остаются в предыдущем исследовании. |
| Работа и переименование | Смена исходного, получение данных, выбор объекта, фильтры, радиусы, подложка и камера автосохраняются. Ручное название переживает смену исходного. |
| Ошибка сохранения | Видны ошибка и «Повторить». Смена исследования ждёт успешного сохранения. |
| «Закрыть», затем «Открыть» | Карта очищается при закрытии. Список показывает дату изменения, фактический радиус и наличие OSM. Открытие восстанавливает принятые геометрии, даты, камеру, фильтры и выбор. |
| Перезапуск | Если черновик оставался активным, появляется «Продолжить исследование». Открытие читает сохранённые файлы без запроса к поставщикам геоданных. |
| Повреждённый файл | Открытие сообщает название проблемного файла. Предыдущее активное исследование сохраняется. |
