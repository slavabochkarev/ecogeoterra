## Кеш и ограничения

| Провайдер | Реализация и границы |
|---|---|
| Nominatim | Файловый TTL 7 суток, интервал 1,1 с между началами запросов внутри процесса, последовательный lock. Нормализация пробелов, до 8 вариантов, ручная отправка. |
| Overpass | TTL 24 ч, интервал 5 с, lock. Ключ SHA-256 URL и полного запроса (координаты с 7 знаками, радиус, правила). `around(radius+25)` + `is_in/pivot` для охватывающих зон, `out body geom`; локально сравнивается точное расстояние с выбранным радиусом. Лимиты запроса 75 с исполнения/128 MiB объявленной памяти, HTTPX 100 с / connect 15 с, ни одного автоповтора. Лимита числа объектов и размера HTTP-ответа в модуле нет. `remark` или неверная структура — ошибка без кеша. На 429 внутренний cooldown 60–3600 с; `Retry-After` API v0.2 клиенту не проксируется. |
| НСПД | `.cache/NSPD` либо `CACHE_DIR/NSPD`, TTL 24 ч по умолчанию (`NSPD_CACHE_TTL_SECONDS`). Обогащение кеширует валидные matched/multiple/not_found по OSM-полям, геометрии, тегам, версии и scope. Эксперимент использует ключ по номеру для исходного и ключ номер + WKB + радиус для буфера. Успешный результат с `coverage=unknown` кешируется. Общий для двух кадастровых сервисов неблокирующий lock и примерно 2 с между операциями на процесс; `Retry-After` число 1–3600 либо запасные 60 с. Межпроцессной координации нет. Площадной запрос и поиск номера эксперимента выполняются без повторов; в обогащении до 1 повтора на временные ошибки каждого обращения. WMS может обратиться к четырём слоям, лимит 10 на слой трактуется как неполный ответ. Интервал процесса ограничивает операции, а не отдельные WMS-подзапросы/внутренние повторы. HTTPX 12 с по умолчанию, connect 5 с. Есть проверка TLS/имени узла, локальный доверенный CA с проверкой отпечатка либо `NSPD_CA_FILE`; отключённые ретраи SDK и подмена адреса. |
| Общее | Запись через временный файл и замену, битый/просроченный кеш пропускается. У Nominatim и Overpass свои подпапки; в EXE по умолчанию `LOCALAPPDATA/EcoGeoTerra/cache`. Квоты диска и плановой очистки в этих модулях нет. Два процесса могут дублировать обращение при cache miss. |

## Геометрия, слои и Esri

- НСПД: `intersects?typeIntersect=fullObject`, земельная категория 36368 для территориального запроса. Оригинальная CRS сохраняется при чтении, затем геометрия валидируется и приводится к WGS84, GeoJSON идёт в порядке `[lon,lat]`. Локальная AEQD с центром в `representative_point()`, `always_xy`. Буфер строится от полного исходного контура. Участки дедуплицируются по номеру и проверяются на пересечение буфера. `parcel_measurement` сначала различает касание и прочее пересечение в WGS84; отображает 0 м без линии. Для непересекающихся использует `nearest_points` по обеим границам в AEQD, включая отверстия и части MultiPolygon. Точки линии возвращаются в WGS84. При невалидности или расхождении топологии после перепроецирования — `undefined` без нуля и линии. OSM использует отдельный расчёт от точки до ближайшей точки геометрии. [Нормализация](../../app/cadastre.py#L26) · [Измерение](../../app/cadastre_experiment.py#L90) · [AEQD](../../app/geo.py) · [Тесты CR-004.1](../../tests/test_parcel_measurement.py)
- Leaflet: один из двух базовых слоёв эксперимента активен, кадастр отделён от тайлов. Canvas для границ, отдельные panes для буфера, исходной обводки, неперехватывающих подписи и измерения. Подписи через внутреннюю точку и проверку вместимости/перекрытий, обновляются на zoom/move/resize. Скрытие границ снимает участки, исходную обводку, измерение, подписи и заливку; буфер остаётся. Фактические стили — сосед `#20B7ED` 2,5 px, исходный `#9333EA` 5 px, выбранный `#0284C7` 5 px, измерение `#DC2626` 2,5 px пунктир `7 5`, буфер `#1760bd` пунктир. Зелёный исходный в раннем отчёте исторический. [Leaflet](../../app/static/cadastre-experiment.js#L275) · [Цвета категорий](../../app/static/cadastre-experiment.css#L9)
- Esri: OSM по умолчанию, зарегистрированы только «Карта (OpenStreetMap)» и «Спутник (Esri World Imagery)» при наличии ключа и SDK. Текущий код EOxCloudless не регистрирует. Используется авторизованный `ibasemaps-api.arcgis.com/arcgis/rest/services/World_Imagery/MapServer`, Esri Leaflet 3.0.19, maxZoom 19, запрос метаданных и тайлов из браузера при выборе. Ключ — значение процесса `ESRI_API_KEY` либо `.env` в корне/рядом с EXE, у пустой переменной приоритет. Включение условно по наличию конфигурации. Кредиты «Powered by Esri» + `copyrightText` из метаданных, OSM — своя атрибуция. Тайм-аут ожидания метаданных 12 с, отдельные сообщения 401/403/498/499/429 и о неполной подложке; диагностика одного неудачного тайла на включение с 6 с; явный возврат к OSM. Историческая серия Research v0.3 для одного исходного участка дала 101/554/952/3016 уникальных записей (100/500/1000/2000 м). У B1000 — около 3,24 MB декодированного ответа, у B2000 — 9,17 MB. В наблюдавшихся ответах `intersects` отсутствовали общий счётчик, курсор и следующая страница; `meta.totalCount` зафиксирован у поиска по номеру. Код отклоняет явные `partial/truncated/hasMore/next`, признаки ошибки и расхождения итогового числа; отсутствие признаков оставляет `coverage=unknown`. WMS в коде отправляет BBOX `lat,lon`; архивные контрольные точки в НСПД дали ожидаемые попадания при `lon,lat` и пустые ответы при текущем порядке. Эта особенность препятствует переиспользованию WMS без отдельной проверки для подбора по точке.

Устойчивый лимит объектов, тела, вершин, частоты, SLA, отсутствие скрытого усечения и поддержка пагинации для используемого веб-маршрута остаются неподтверждёнными. Исторически успешный ответ одного участка характеризует конкретный запрос. В CR-006 новых запросов к НСПД не выполнялось. Протокол НСПД и серия B1000/B2000 хранятся локально в `research-v03`.
