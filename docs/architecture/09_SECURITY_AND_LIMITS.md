# Безопасность и ограничения

**Назначение** — перечислить реализованные проверки, границы локального доступа и различия между лимитами приложения и политиками поставщиков.

## Реализованные механизмы

| Область | Проверка |
|---|---|
| Номера | `CadastralNumber` удаляет крайние пробелы, максимум 40, сегменты ASCII-цифр 2:2:1–12:1–14. Поиск источника сверяет точный номер и категорию. UI проверяет формат до запроса. |
| Координаты | OSM и кандидаты у точки принимают конечные широты ±85° и долготы ±180°. Пользовательская карта допускает до ±85,05112878°. WGS 84 GeoJSON и файловые MapPoint — до ±90/±180. Для legacy `coordinates:[lon,lat]` широта ограничена ±85°. |
| Радиусы | Кадастровый bounded API требует JSON int 500/1000/2000. 1000/2000 включаются независимо; отключённый отклоняется до НСПД. Legacy 500 м фиксирован, кандидаты 15 м фиксированы, OSM 500/1000/2000 независимо от флагов НСПД. |
| Геометрия | CRS и валидность по Shapely/pyproj, пространственное отсечение буфером, проверка попаданий. Bounded-профиль по умолчанию 60 км², 6000 позиций источника/буфера, 256 КиБ запроса, 16 МиБ ответа, 5000 записей и 250 000 координат. Проверка усечения не заменяет подтверждение полноты. |
| НСПД | Явный локальный TLS context с проверкой имени и сертификата, комплектный CA с отпечатком или настройка CA. Синхронизация в процессе, cooldown 3 с bounded-ветки, до пяти различных flights и 10 с ожидания lock при общем дедлайне 35 с. HTTPX 12/5 с по умолчанию. Bounded не повторяет HTTP, отдельные legacy-операции имеют максимум один временный повтор. |
| Nominatim / Overpass | Сериализация и кеш по URL/параметрам; интервалы 1,1 с/5 с на процесс, HTTPX 10/5 с и 100/15 с соответственно. Overpass QL задаёт 75 с и 128 МиБ на сервере. Ошибка `remark` отклоняет ответ. Оба клиента без автоповторов. |
| Файлы исследований | UUID типизирован FastAPI; проверяются путь каталога и обычные локальные дочерние файлы, символьные ссылки на файлы отклоняются. Версия манифеста, размер, контрольные суммы, номер участка и строгая схема проверяются. Клиент не передаёт пути файлов. Общая блокировка и атомарные commit по манифесту. |
| JSON и вывод | Лимит HTTP-тела 57 МиБ + 256 КиБ и отдельные квоты файлов/координат. Наборы отбирают поля по allowlist, удаляются некоторые известные имена секретных OSM-тегов. UI отчётов вставляет текст через `textContent` и экранирует Markdown при выгрузке. CSV в Map First защищает значения от интерпретации как формулы. |
| Ключ Esri | Браузер получает ключ в `no-store` с CORP `same-origin`. При сохранении исследования ключ не включается. Ключ доступен клиенту по своему назначению и должен ограничиваться через настройки Esri. |

## HTTP 429, 503 и ошибки внешних ответов

Bounded НСПД читает числовой или датированный `Retry-After`, приводит к 1–3600 с с запасным 60 с и запоминает cooldown. Маршрут отвечает HTTP 429 с кодом и передаёт заголовок. Старый кадастр использует свою форму `detail`, legacy enrichment может вернуть HTTP 200 со статусом unavailable и кодом. НСПД 5xx или сетевой отказ bounded переводит в HTTP 503, явное усечение в 502, дедлайн в 504. Nominatim/Overpass при 429 применяют 60–3600 с для числового заголовка и 60 с для прочего; заголовок локальному клиенту не проксируется. Прочие внешние HTTP-ошибки Nominatim/Overpass дают 502, таймаут 504. Ошибки I/O постоянного хранилища также дают 503. См. [коды API](04_API_REFERENCE.md#ошибки-ограниченного-кадастрового-api).

## Границы и риски

- Штатные запуски слушают `127.0.0.1`. Пользовательской аутентификации, авторизации, владения UUID, изоляции проектов по пользователям и отдельного прикладного CSRF-механизма нет. Одна активная запись общая для всех вкладок каталога. Публичное размещение и устойчивость нескольких workers не подтверждены.
- Файлы исследований и кеши — открытый JSON на диске. Они могут содержать адреса, кадастровые номера, координаты, имена и исходные теги. Доступ определяется ОС. Контрольная сумма полезна для согласованности, но не подписывает происхождение данных.
- Лимиты внешних запросов локальны для процесса. У Overpass нет локального streaming-лимита объёма и числа записей в `services.py`; `maxsize` задан в запросе поставщику. У общего каталога кеша и каталога исследований нет общей квоты. Прозрачное перенаправление HTTPX в клиентах OSM отличается от закрытого TLS-шлюза НСПД.
- Атрибуция активных OSM-тайлов видима и содержит ссылку на данные OSM/ODbL, сохранена в ходе смены подложек и для используемых результатов. Браузер следует HTTP-кешированию тайлов; приложение не реализует массовую выгрузку тайлов. Для Esri показаны `Powered by Esri` и кредит метаданных снимков. Проверка условий для конкретного ключа, origin и режима размещения зависит от владельца установки. [OSM Tiles Policy](https://operations.osmfoundation.org/policies/tiles/) · [Лицензия OSM](https://www.openstreetmap.org/copyright) · [Условия Esri](https://developers.arcgis.com/esri-leaflet/terms-of-use/).
- Публичный Nominatim требует суммарно максимум 1 запрос/с на приложение, идентифицирующий HTTP заголовок, атрибуцию и учёт политики приватности. Сервис запрещает автодополнение и систематические запросы. Разделение на несколько процессов не увеличивает разрешённую частоту. [Политика Nominatim](https://operations.osmfoundation.org/policies/nominatim/).
- Контрактные квоты НСПД и Overpass для всех территорий и радиусов не подтверждены. Полнота и актуальность выборок не гарантируются; группировка ВРИ не является подтверждением применимости норм.
