# Архитектурная документация ЭкоГеоТерры

**Назначение** — точка входа в документацию As-Is для разработчиков и сопровождающих. ЭкоГеоТерра — локальное картографическое рабочее место для ручного обследования территории, кадастровых исследований и выгрузок. Основной интерфейс — [Map First на 8000](http://127.0.0.1:8000/).

**Актуализировано 20.11.2026** после [CR-008.1](../CR-008/README.md), [CR-008.2](../CR-008/02_CADASTRE_2000_DESIGN.md) и [CR-011.1](../CR-011.1/README.md). Базовая ревизия обследования `3ad1bbc`. `/api/health` возвращает версию приложения `0.2.0`.
