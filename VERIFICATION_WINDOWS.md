# ЭкоГеоТерра v0.2 — проверка Windows-выпуска

Дата: **14 ноября 2026 года**, Europe/Samara. Windows 11 x64, build 26200; Python 3.12.10 x64, PyInstaller 6.22.3, hooks-contrib 2026.10. Формат `onedir`, оконный EXE без консоли.

## Результат

Пересобрана подтверждённая пользователем версия v0.2 с адаптером НСПД и исправленным TLS. Продуктовая логика, интерфейс, классификация, карта и экспорт при пересборке не менялись. CA НСПД включён в `_internal/app/certs/russian_trusted_root_ca.pem`; его DER SHA-256 проверяется при упаковке и при создании SSL-контекста.

## Архив и запуск

Распространяемый файл: **`EcoburoGeo-v0.2-win64.zip`**. Рядом — `EcoburoGeo-v0.2-win64.zip.sha256`. Старый ZIP v0.1 сохранён отдельно.

Распакуйте всю папку `EcoburoGeo` и запустите `EcoburoGeo.exe`. `_internal` должен оставаться рядом с EXE. Python устанавливать и CA в Windows импортировать не нужно. Для обычного запуска NSPD_CA_FILE не требуется. Нужны браузер и интернет для публичных геосервисов.

Пакет содержит только onedir-сборку и четыре пользовательских документа: README.md, START_HERE.txt, BUILD_WINDOWS.md, VERIFICATION_WINDOWS.md. Описание происхождения CA находится в `_internal/app/certs/README.md`. Упаковщик разрешает только два публичных PEM-ресурса: этот CA и certifi/cacert.pem; посторонние PEM/ключи отклоняются.

## Границы проверки

- Отдельной чистой Windows без установленного Python не было. Запуск с PATH без Python на сборочной машине и наличие всех DLL не заменяют проверку на такой машине. Windows 10 отдельно не проверялась.
- В этом прогоне не повторялся полный цикл OSM/Overpass и экспорт CSV/JSON из браузера; их код не менялся. Проверены выдача локальных ресурсов и реальное обогащение НСПД через API собранного приложения.
- Сценарий занятого порта покрыт регрессионным тестом оболочки; второй EXE ради него не запускался.
- Успех относится к одному контуру и одному найденному участку. WMS в точке, поиск ОКС и полнота НСПД на других территориях отдельно не проверялись.
- EXE не подписан цифровым сертификатом. Настройки защиты Windows не менялись.

Предупреждение hook pyproj об альтернативном каталоге `.venv/Library/share/proj` не препятствует работе: реальный `pyproj/proj_dir/share/proj/proj.db` включён, пространственное сопоставление успешно выполнено в EXE. Необязательные модули POSIX, WebSocket/uvloop, CLI и типизационные импорты из списка PyInstaller не используются в проверенном сценарии.

Исторический отчёт v0.1 оставлен в исходниках: `docs/VERIFICATION_WINDOWS_V01.md`.
