# ЭкоГеоТерра v0.2 — сборка Windows x64

## Готовый переносимый выпуск

Архив `EcoburoGeo-v0.2-win64.zip` содержит одну папку `EcoburoGeo`. Распакуйте её целиком на Windows 10/11 x64 и запустите **`EcoburoGeo.exe`**. Установленный Python, PowerShell-скрипты, pip и права администратора для обычного запуска не нужны.

```text
EcoburoGeo/
  EcoburoGeo.exe
  _internal/           # Python 3.12, библиотеки/DLL, PROJ, Tcl/Tk, HTML/CSS/JS, Leaflet
  START_HERE.txt
  README.md
  BUILD_WINDOWS.md
  VERIFICATION_WINDOWS.md
```

Нельзя переносить только EXE, удалять `_internal` или запускать EXE прямо из ZIP. Лучше использовать обычную пользовательскую папку с путём без ограничений доступа. Браузер и интернет необходимы для получения геоданных; Python уже внутри дистрибутива. EXE не подписан цифровым сертификатом: этот выпуск не меняет настройки Windows или антивируса.

После запуска появится небольшое окно «ЭкоГеоТерра v0.2». Оно открывает браузер **после** успешной проверки готовности сервера. Если автоматическое открытие не удалось, локальный адрес можно скопировать из окна или нажать «Открыть в браузере».

Сервер привязан исключительно к **127.0.0.1**. Сначала резервируется порт 8000; если он занят, проверяются следующие 19 портов, затем ОС выбирает свободный порт. Зарезервированный сокет передаётся серверу, поэтому между проверкой и запуском порт не освобождается. Чужой процесс на занятом порту не завершается.

Закройте **окно приложения** или нажмите **«Завершить»**. Закрытие вкладки браузера не является завершением приложения. Сервер работает в одном дочернем процессе; окно посылает сигнал остановки и ждёт до 4 секунд. Если незавершённый внешний запрос мешает выходу, завершается только принадлежащий этому окну дочерний процесс.

Пользовательский кеш и журналы создаются вне папки дистрибутива:

- `%LOCALAPPDATA%\EcoGeoTerra\cache` — ответы Nominatim/Overpass/НСПД.
- `%LOCALAPPDATA%\EcoGeoTerra\logs\launcher.log` — запуск, выбранный порт и открытие браузера.
- `%LOCALAPPDATA%\EcoGeoTerra\logs\server.log` — сообщения сервера. Журналы ограничены по размеру.

При переносе на другой компьютер кеш и журналы переносить не требуется. Запросы к публичным API сохраняют прежние ограничения частоты и TTL. Переопределения `NOMINATIM_URL`, `OVERPASS_URL`, `OSM_USER_AGENT`, `CACHE_DIR` применяются при запуске EXE так же, как у исходной версии; значения окружения сборочной машины в EXE не записываются.

## Сборка из исходников

Собирать нужно **на Windows x64**, с **Python 3.12 x64**. PyInstaller не используется как кросс-компилятор для Windows из Linux/macOS.

Из каталога проекта запустите:

```powershell
.\build_windows.cmd
```

CMD вызывает PowerShell с политикой только для этого запуска; системная политика исполнения скриптов не изменяется. Также можно выполнить:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build_windows.ps1
```

Скрипт создаёт/использует `.venv`, проверяет Python 3.12 x64, устанавливает `requirements-build.txt`, запускает тесты, собирает `EcoburoGeo.spec` и упаковывает результат. Ключ `-SkipInstall` предназначен для повторной сборки в уже подготовленном окружении.

Используются PyInstaller **6.22.3**, hooks-contrib **2026.10** и версии рабочих зависимостей из `requirements.txt`. Конфигурация — **onedir**, оконный EXE без консоли; UPX отключён. Для multiprocessing вызывается `freeze_support()`. Hooks PyInstaller собирают DLL Shapely, PROJ и его базы данных, TLS-сертификаты certifi и Tcl/Tk. Статические ресурсы добавляются явно в `_internal/app/static` и ищутся через `__file__`, без зависимости от текущего каталога.

Результаты:

```text
dist/EcoburoGeo/EcoburoGeo.exe
EcoburoGeo-v0.2-win64.zip
EcoburoGeo-v0.2-win64.zip.sha256
```

`scripts/package_windows.py` проверяет формат PE x64, обязательные ресурсы и отсутствие известных артефактов разработки, затем создаёт ZIP только из `dist/EcoburoGeo/` и проверяет CRC архива. Исторические отчёты/скриншоты, `.cache`, `.venv`, `.env`, временные файлы, тесты и исходники проекта целиком в архив не добавляются. Публичные `certifi/cacert.pem` и `app/certs/russian_trusted_root_ca.pem` необходимы для HTTPS и являются явными исключениями среди `.pem`. CA НСПД и описание его происхождения добавлены в `_internal/app/certs`; упаковщик проверяет DER SHA-256 сертификата. Системное хранилище Windows не меняется, `NSPD_CA_FILE` для обычного запуска не нужен.

При сборке вручную:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean EcoburoGeo.spec
.\.venv\Scripts\python.exe scripts\package_windows.py
```

Сборка повторно создаёт результат в `dist/EcoburoGeo`; не храните пользовательские файлы в папке сборки. Для распространения используйте только полученный ZIP, без добавления локального кеша или секретов. SHA-256 можно сверить:

```powershell
Get-FileHash .\EcoburoGeo-v0.2-win64.zip -Algorithm SHA256
```

## Проверка перед переносом

Фактические результаты текущей сборки записаны в **`VERIFICATION_WINDOWS.md`**. Проверка на этой машине не заменяет проверку на отдельной чистой Windows 10/11 x64 без Python.

1. Распаковать ZIP в новую папку, запустить EXE из другого рабочего каталога.
2. Убедиться, что окно и браузер открылись, сервер слушает только 127.0.0.1.
3. Повторить запуск при занятом порту 8000: второй сервер должен выбрать другой порт.
4. Найти произвольный адрес, выбрать точку, проверить карту и все три радиуса.
5. Запросить объекты OSM, выбрать объект, проверить фильтры и исходные теги.
6. Скачать JSON и CSV, проверить содержимое.
7. Закрыть окно приложения и убедиться, что его процессы завершились, а выбранный порт больше не слушается.

Nominatim может не найти точный адрес, Overpass может отказать из-за нагрузки, а сервер тайлов — не отдать подложку. Такие случаи следует отличать от отсутствующих ресурсов или ошибок EXE. Алгоритмы расстояний, направлений, геометрии и классификации в переносимом выпуске не изменены.

Источники по сборке: [spec-файлы PyInstaller](https://pyinstaller.org/en/stable/spec-files.html), [runtime paths](https://pyinstaller.org/en/stable/runtime-information.html), [multiprocessing и запуск внешних программ](https://pyinstaller.org/en/stable/common-issues-and-pitfalls.html).
