ЭкоГеоТерра v0.2 — переносимая Windows-версия

1. Распакуйте ZIP целиком в обычную папку на Windows 10/11 x64.
2. Запустите EcoburoGeo.exe. Python устанавливать не нужно.
3. Дождитесь открытия браузера. Если он не открылся, нажмите
   «Открыть в браузере» или скопируйте локальный адрес из окна.
4. Введите адрес предприятия, выберите результат и проверьте точку.
5. Выберите радиус и нажмите «Исследовать».
6. Выберите объект в правом списке и нажмите
   «Получить кадастровые сведения», если они нужны.
7. Закройте окно «ЭкоГеоТерра v0.2», чтобы завершить сервер.

Не отделяйте EcoburoGeo.exe от папки _internal.
Не запускайте EXE прямо из ZIP.
Сервер доступен только на этом компьютере (127.0.0.1).
Доступ к интернету необходим для карты, Nominatim, Overpass и НСПД.
Ошибки или перегрузка публичных OSM API возможны независимо от EXE.
Доверенный CA НСПД включён в _internal/app/certs.
Проверка TLS-сертификатов и имени сервера включена.
Для обычного запуска NSPD_CA_FILE задавать не требуется.

Кеш:     %LOCALAPPDATA%\EcoGeoTerra\cache
Журналы: %LOCALAPPDATA%\EcoGeoTerra\logs

Подробности: README.md и BUILD_WINDOWS.md.
OSM не является официальным кадастровым источником.
Классификация по тегам не определяет юридический ВРИ.
